# 优优电商 OMS 高保真原型

本项目用于承载优优业务中台 OMS 与 eBay 客服高保真原型。当前已完成全局壳层、菜单占位、原型标注底座，以及“OMS → 销售订单”下的“全渠道订单”列表与应用内详情页签、“eBay订单”列表与详情原型；其余叶子菜单仍为占位页。

## 在线预览与源码交付

- 在线预览（受控访问）：[优优电商 OMS 高保真原型](https://youyou-oms-prototype.hearty-fawn-2662.chatgpt.site)
- 源码通过 GitHub 私有仓库交付；获得仓库权限后可使用 `Code → Download ZIP` 下载，或通过 Git 克隆。
- 原型内订单、买家、联系方式和业务编号均为虚构、脱敏的演示数据，不得作为真实生产数据使用。

## 页面与菜单

- 菜单和路由统一从 `src/配置/菜单.ts` 生成。
- 现有中台菜单来自 2026-09-04 对测试环境当前账号可见菜单的实际核验。
- 核验证据边界见 `../文档/业务现状/当前中台菜单与壳层核验记录.md`。
- 已实现页面通过 `src/路由/index.ts` 的 `已实现页面` 注册表接入；未实现叶子菜单继续打开占位页。
- 全渠道订单原型使用七个平台的虚构、脱敏通用订单样例，覆盖自配送、平台履约、六态、处理状态为空、SKU 查询失败、取消不发货和跨仓多路由等评审场景。完整详情固定在中台顶部新页签打开；列表已加入查询方案、自定义列和批量选择框架。
- 当前只有 eBay 状态投影按已确认来源展示。Temu、美客多、Coupang、OZON、TikTok Shop 和乐天尚未接入，相关订单、状态和同步信息统一显示为原型占位，不写入或伪装成真实平台状态。
- eBay订单原型使用完全虚构、脱敏的本地样例，覆盖多商品、多包裹、待关联、SKU 未识别、平台履约、取消退款、系统外履约和未知枚举等评审场景。

## 原型标注

需要标注的元素使用 `v-prototype` 绑定结构化说明。标注不是页面旁注，而是面向研发和测试的“页面逻辑执行卡”：应能从页面节点直接定位到触发条件、系统动作、结果、异常和验收口径。

```vue
<ElButton
  v-prototype="{
    id: 'oms.order.review.submit',
    标题: '提交审核',
    说明: '提交订单进入审核流程。',
    事实等级: '待确认',
    prd引用: ['PRD/订单审核.md#提交审核'],
    前置条件: ['订单已完成必要字段校验。'],
    触发方式: ['点击提交审核。'],
    系统动作: ['写入审核轮次并执行审核规则。'],
    成功结果: ['订单进入待推单。'],
    异常处理: ['命中拦截规则时保留原因并停留在当前状态。'],
    数据来源: ['订单字段、SKU 映射和库存能力。'],
    权限与审计: ['记录操作者、时间、前后状态和决策摘要。'],
    验收要点: ['覆盖成功、拦截、重复提交和权限不足。'],
  }"
>
  提交审核
</ElButton>
```

顶部工具栏的“标注模式”打开后，带有 `v-prototype` 的节点会显示虚线锚点；单击或聚焦后按 Enter/Space 打开右侧说明抽屉。关闭标注模式时，指令不会拦截业务点击、输入、悬停或快捷键。页面重构时应保持 `id` 稳定，`prd引用` 使用仓库内文档路径和标题锚点。

可选字段的使用口径：

- `前置条件`：研发实现或测试操作前必须满足的状态、权限和数据条件。
- `触发方式`：用户动作、系统事件或时间条件。
- `系统动作`：前端交互、接口/任务、状态写入和路由行为。
- `成功结果`：用户可观察结果及业务对象最终变化。
- `异常处理`：失败、重复、缺失、未知枚举和人工核查路径。
- `数据来源`：页面字段对应的平台、OMS、仓库或本地投影来源。
- `权限与审计`：角色、数据范围、敏感数据和操作留痕要求。
- `验收要点`：研发自测和测试用例应覆盖的最小场景集合。
